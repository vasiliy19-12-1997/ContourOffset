# Области поверхности из DWG и смещение контуров

Расширение pyRevit для топоповерхностей в Revit 2021–2023.

## Установка

Распакуйте `ContourOffset.zip` и скопируйте папку `ContourOffset.extension` в `%APPDATA%\pyRevit\Extensions`. При обновлении объедините папки с заменой файлов. Нажмите **pyRevit → Обновить**. Обе команды находятся на вкладке **A101 Контуры → Топография**.

## Области из DWG

1. Выберите размещённую подложку и запустите **Области из DWG**.
2. Укажите слой и выберите **Заливки** или **Замкнутые полилинии и цепочки линий**.
3. Проверьте имя (`Газон`), IFC-класс (`IfcCivilElement`) и материал (`Озеленение`). Значения можно изменить или оставить пустыми.
4. Выберите топоповерхность. Перед подтверждением проверьте число областей, их привязку и список пропусков.

Команда создаёт отдельную область для каждого внешнего контура и сохраняет отверстия. В параметр **Площадь озеленения** записывается спроецированная площадь на момент создания.

### Если границы штриховок недоступны

1. Откройте копию DWG в AutoCAD на вкладке **Модель** и через `APPLOAD` загрузите `A101_HatchBoundaries.lsp`.
2. Запустите `A101_HATCH_BOUNDARIES` и укажите слой штриховок. По умолчанию используется `1_landscaping`.
3. Загрузите DWG в Revit с тем же размещением. Выберите созданный слой с суффиксом `_BOUNDARIES` и режим **Замкнутые полилинии и цепочки линий**.

## Сместить контур

Выйдите из режима **Редактировать границу**, выберите область поверхности и запустите **Сместить контур**. Задайте расстояние в миллиметрах и выберите **Наружу** или **Внутрь**. Команда смещает все контуры области за одну операцию. Отмена — **Ctrl+Z**.
